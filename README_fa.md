# سامانه قیمت‌گذاری ارزی برنا سنسور (نسخه ۱٫۱)

این بسته قدم‌های ۴، ۵ و ۶ پروژه را اجرا می‌کند:

- **قدم ۴، خواندن نرخ:** در ساعت کاری، هر ۶۰ دقیقه نرخ دلار بازار آزاد را از API رایگان priceto.day (که داده tgju را می‌دهد و کلید نمی‌خواهد) می‌خواند و سه کنترل روی آن انجام می‌دهد. الان‌چند هم به‌عنوان منبع جایگزین در تنظیمات هست.
- **قدم ۵، هسته:** قیمت ۲۷ کالا را با فرمول قدم ۱ حساب می‌کند، تصمیم انتشار و تأیید را می‌گیرد و همه نرخ‌ها، محاسبه‌ها، انتشارها و تصمیم‌ها را با تاریخ و نام کاربر نگه می‌دارد.
- **قدم ۶، وب‌سایت داخلی:** داشبورد فارسی برای فروش و مدیران، لیست قیمت چاپی و Excel، تاریخچه نرخ و قیمت هر کالا.

هوش مصنوعی هیچ قیمتی را حساب نمی‌کند؛ محاسبه قطعی و قابل بازبینی است و نتیجه‌اش با فایل اکسل قدم ۳ یکی است (۱۰۸ قیمت در آزمون‌ها مقایسه شده است).

## نصب روی ویندوز

1. Python 3.12 را نصب کنید. در اولین صفحه نصب، گزینه **Add python.exe to PATH** را تیک بزنید.
2. فایل zip را در یک پوشه روی همین رایانه باز کنید، مثلاً `C:\BornaPricing`.
3. روی `install_windows.bat` دوبار کلیک کنید. خودش پایتون را پیدا می‌کند: دستورهای `py` و `python`، و پوشه‌های معمول نصب python.org، مدیر نصب پایتون، Anaconda و Miniconda. بعد رمز کاربر `admin` را دو بار می‌پرسد (دست‌کم ۸ نویسه).
   اگر پایتون را پیدا نکرد، گزارش می‌دهد چه چیزی روی رایانه هست. در این حالت فایل `python.exe` را با موس روی `install_windows.bat` بکشید و رها کنید، یا در Command Prompt بنویسید: `install_windows.bat "C:\مسیر\کامل\python.exe"`
4. `test_api_windows.bat` را اجرا کنید. منبع پیش‌فرض priceto.day است و توکن نمی‌خواهد. باید چیزی شبیه این ببینید:
   `موفق. usd/price = 270,500 تومان (= 2,705,000 ریال)`
5. `start_windows.bat` را اجرا کنید و پنجره‌اش را باز بگذارید. اولین بار ویندوز درباره دیوار آتش می‌پرسد؛ **Private networks** را اجازه دهید.
6. در مرورگر همین رایانه: `http://127.0.0.1:8080`. رایانه‌های دیگر شبکه نشانی‌ای را باز کنند که در پنجره سامانه چاپ می‌شود (مثل `http://192.168.1.20:8080`).

**روشن شدن خودکار:** در Task Scheduler یک Task بسازید: Trigger = At startup، Action = اجرای `start_windows.bat` با Start in = پوشه سامانه، و گزینه «Run whether user is logged on or not».

## به‌روزرسانی از نسخه ۱٫۰ به ۱٫۱

در نسخه ۱٫۱ منبع نرخ از الان‌چند به priceto.day عوض شده است. پایگاه‌داده، کاربران، لیست‌ها و `settings.ini` دست نمی‌خورند و تاریخچه نرخ‌های الان‌چند می‌ماند.

1. پنجره سیاه سامانه (`start_windows.bat`) را ببندید.
2. برای احتیاط، پوشه `data` و فایل `settings.ini` را جای دیگری کپی کنید.
3. فایل zip تازه را در یک پوشه جدا باز کنید.
4. از پوشه تازه، همه چیز **به‌جز پوشه `data`** را کپی کنید و در پوشه سامانه (مثلاً `D:\Borna_Pricing`) بچسبانید. وقتی ویندوز پرسید، **Replace the files in the destination** را بزنید.
5. لازم نیست `settings.ini` را عوض کنید: وقتی بخش `[source]` در آن نیست، منبع خودکار priceto.day است. توکن الان‌چند همان‌جا می‌ماند و به کار نمی‌آید.
6. `test_api_windows.bat` و بعد `start_windows.bat` را اجرا کنید. در پنجره سامانه باید «منبع نرخ دلار: priceto.day» ببینید.

برای برگشت به الان‌چند، این دو خط را به `settings.ini` اضافه کنید و سامانه را دوباره روشن کنید:

```ini
[source]
provider = alanchand
```

## نصب روی اوبونتو

```bash
sudo apt install -y python3-venv unzip
sudo useradd --system --create-home --home-dir /opt/borna_pricing borna
unzip Borna_Pricing_v1.1.zip -d /tmp/
sudo cp -r /tmp/Borna_Pricing/. /opt/borna_pricing/
sudo chown -R borna:borna /opt/borna_pricing
cd /opt/borna_pricing
sudo -u borna ./install_ubuntu.sh                       # رمز admin را می‌پرسد
sudo -u borna .venv/bin/python -m borna_pricing test-api
sudo cp borna-pricing.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now borna-pricing
journalctl -u borna-pricing -f                          # دیدن گزارش زنده
```

**اگر سرور از اینترنت در دسترس است:** در `settings.ini` مقدار `host = 127.0.0.1` و `behind_https_proxy = true` بگذارید و nginx با گواهی HTTPS جلوی سامانه قرار دهید:

```nginx
server {
    listen 443 ssl;
    server_name price.example.ir;
    ssl_certificate     /etc/ssl/price.crt;
    ssl_certificate_key /etc/ssl/price.key;
    location / {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $remote_addr;
        proxy_set_header X-Forwarded-Proto https;
    }
}
```

بدون HTTPS، رمزها روی اینترنت بی‌رمز جابه‌جا می‌شوند؛ روی شبکه داخلی دفتر مشکلی نیست.

## روز اول کار، قدم به قدم

1. سامانه در ساعت کاری خودش نرخ را می‌گیرد. اولین نرخ (مثلاً ۲۷۳٬۴۰۰ تومان) نسبت به نرخ مبنا (۲۶۰٬۰۰۰) **۵٫۱۵ درصد** بالاتر است، یعنی بیش از سقف جهش ۳ درصد؛ پس «در انتظار تأیید» می‌ماند.
2. تأییدکننده (مالی یا مدیرعامل) وارد می‌شود و در بالای داشبورد **«پذیرفتن نرخ و محاسبه قیمت‌ها»** را می‌زند.
3. قیمت‌ها حساب می‌شود. چون تغییر نسبت به لیستِ ابتدای روز بیش از ۵ درصد است، دکمه **«انتشار لیست تازه»** فقط بعد از تیک تأیید فعال می‌شود.
4. بعد از انتشار، فروش لیست رسمی تازه را در داشبورد می‌بیند، چاپ می‌کند یا Excel می‌گیرد. لیست **تا پایان روز کاری** معتبر است.
5. روزهای بعد، اگر دلار کمتر از ۲ درصد با نرخ لیست جاری فاصله داشته باشد، اعتبار لیست خودکار تا پایان همان روز تمدید می‌شود. اگر بیشتر شود، کادر «لیست تازه آماده انتشار است» ظاهر می‌شود.

**نوار فاصله** در داشبورد نشان می‌دهد دلار امروز چقدر از نرخ لیست رسمی فاصله دارد: وسط (کمتر از ۲٪) یعنی نیازی به انتشار نیست، زرد یعنی انتشار لازم است، قرمز یعنی انتشار با تأیید. قاب آبی جای نرخی است که منتظر تأیید است.

## قواعد (تأییدشده در قدم ۱)

| قاعده | مقدار |
|---|---|
| فرمول | قیمت = قیمت پایه × (α × دلار امروز ÷ ۲۶۰٬۰۰۰ + ۱ − α)، با α = ۱ |
| گرد کردن | نزدیک‌ترین ۵۰۰٬۰۰۰ ریال (نیمه به بالا، مثل ROUND اکسل) |
| انتشار | وقتی تغییر بیش از ۲٪ باشد؛ همیشه کل لیست منتشر می‌شود |
| تأیید | تغییر بیش از ۵٪ نسبت به لیستِ ابتدای روز، با تأیید مدیرعامل یا مالی |
| اعتبار | تا پایان روز کاری: شنبه تا چهارشنبه ۱۷:۰۰، پنجشنبه ۱۳:۰۰، جمعه تعطیل |
| دوره آزمایشی | انتشار خودکار خاموش است؛ هر انتشار را یک نفر می‌زند |
| ذخیره و نمایش | ذخیره به ریال؛ نمایش به ریال و تومان |

**کنترل‌های نرخ (قدم ۴):**

| کنترل | رفتار |
|---|---|
| کهنگی | اگر منبع بیش از ۱۸۰ دقیقه **از ساعت کاری** به‌روز نشده باشد، نرخ استفاده نمی‌شود |
| جهش | تغییر بیش از ۳٪ نسبت به آخرین نرخ پذیرفته‌شده، تا تأیید نگه داشته می‌شود |
| بازه | نرخ باید بین ۱۰۰٬۰۰۰ و ۲٬۰۰۰٬۰۰۰ تومان باشد (اگر کسی ریال وارد کند، رد می‌شود) |
| فاصله دریافت | سامانه هر ۶۰ دقیقه یک بار می‌پرسد، حتی اگر کسی دکمه «دریافت نرخ الان» را بزند |

**چرا کهنگی فقط در ساعت کاری شمرده می‌شود:** بازار آزاد شب و جمعه معامله نمی‌کند، پس آخرین نرخ دیشب تا وقتی بازار امروز باز شود تازه‌ترین نرخ موجود است. priceto.day هم معمولاً تا اواخر صبح نرخ دیشب را نشان می‌دهد. اگر کهنگی با ساعت دیواری شمرده می‌شد، هر روز صبح نرخ رد می‌شد و لیست تا ظهر «منقضی» می‌ماند. حالا ساعت ۹ صبح نرخ دیشب پذیرفته می‌شود، ولی اگر منبع تا ساعت ۱۲ هم به‌روز نشود، نرخ رد می‌شود.

### یک تصمیم فنی: تغییر را چطور بسنجیم؟

با گرد کردن به ۵۰۰٬۰۰۰ ریال، برای کالاهای زیر ۲۵ میلیون ریال **هر پله گرد کردن خودش بیش از ۲٪ است**. اگر قاعده ۲٪ روی قیمت گردشده سنجیده شود، یک نوسان ۰٫۲۹ درصدی دلار (مثلاً از ۲۷۴٬۰۰۰ به ۲۷۴٬۸۰۰) قیمت یک کالای ۲۲ میلیونی را از ۲۳٫۰ به ۲۳٫۵ میلیون می‌برد و لیست تازه لازم می‌شود، و این می‌تواند در یک روز چند بار رفت‌وبرگشت کند.

برای همین سامانه تغییر را روی **قیمت دقیق پیش از گرد کردن** (یعنی اثر خود دلار) می‌سنجد: `change_basis = exact`. اگر رفتار فایل اکسل قدم ۳ را می‌خواهید، در `settings.ini` بنویسید `change_basis = rounded`. کالای تازه یا کالایی که قیمت پایه‌اش عوض شده، در هر دو حالت همیشه انتشار تازه لازم دارد.

## تنظیمات (`settings.ini`)

بعد از هر تغییر، سامانه را خاموش و روشن کنید. فایل را با کدگذاری UTF-8 ذخیره کنید.

| بخش و کلید | معنی | مقدار فعلی |
|---|---|---|
| `[source] provider` | منبع نرخ: `pricetoday` یا `alanchand` | `pricetoday` |
| `[source] mode` | `live` از اینترنت، `file` از فایل نمونه (آزمون)، `off` فقط نرخ دستی | `live` |
| `[source] timeout_seconds` | بیشترین انتظار برای پاسخ API (ثانیه) | `20` |
| `[pricetoday] url` | نشانی نرخ دلار آزاد؛ تغییر ندهید | `https://api.priceto.day/v1/latest/irr/usd` |
| `[pricetoday] unit` | واحد عدد پاسخ (priceto.day ریال می‌دهد) | `rial` |
| `[pricetoday] sample_file` | فایل نمونه برای حالت `file` | پاسخ نمونه priceto.day |
| `[alanchand] token` | توکن API الان‌چند؛ فقط وقتی `provider = alanchand` است لازم است | `PUT_YOUR_TOKEN_HERE` |
| `[alanchand] url`، `type` | نشانی و نوع درخواست؛ تغییر ندهید | `https://api.alanchand.com/`، `currencies` |
| `[alanchand] slug` | کدام ارز: `usd` دلار نقدی آزاد، `usd-hav` حواله | `usd` |
| `[alanchand] field` | `sell` نرخ فروش، `buy` نرخ خرید | `sell` |
| `[alanchand] unit` | واحد عددهای API (الان‌چند تومان می‌دهد) | `toman` |
| `[alanchand] sample_file` | فایل نمونه برای حالت `file` | پاسخ نمونه الان‌چند |
| `[alanchand] source_utc_offset_minutes` | منطقه زمانی `updated_at` در پاسخ API؛ تهران ۲۱۰ دقیقه | `210` |
| `[pricing] base_rate_toman` | نرخ مبنای دلار (تومان) | `260000` |
| `[pricing] base_date`، `base_time` | تاریخ و ساعت لیست پایه برنا | `1405/07/20`، `09:00` |
| `[pricing] alpha_default` | سهم ارزی پیش‌فرض α (بین ۰ و ۱) | `1` |
| `[pricing] round_step_rial` | گام گرد کردن (ریال) | `500000` |
| `[pricing] publish_threshold` | آستانه انتشار (۰٫۰۲ یعنی ۲٪) | `0.02` |
| `[pricing] approval_threshold` | آستانه تأیید نسبت به لیستِ ابتدای روز | `0.05` |
| `[pricing] change_basis` | `exact` تغییر قیمت دقیق، `rounded` تغییر قیمت گردشده | `exact` |
| `[pricing] auto_publish` | انتشار خودکار وقتی تأیید لازم نیست | `false` |
| `[pricing] auto_renew` | تمدید خودکار اعتبار وقتی انتشار لازم نیست | `true` |
| `[guards] fetch_interval_minutes` | فاصله دریافت نرخ (دقیقه)؛ priceto.day هر ۳۰ دقیقه به‌روز می‌شود و طرح رایگان الان‌چند ساعتی یک درخواست می‌دهد | `60` |
| `[guards] retry_minutes` | تلاش دوباره وقتی سرور منبع در دسترس نبود | `10` |
| `[guards] max_age_minutes` | بیشترین قدمت مجاز نرخ در منبع؛ فقط دقیقه‌های ساعت کاری شمرده می‌شود | `180` |
| `[guards] jump_threshold` | سقف جهش نسبت به آخرین نرخ پذیرفته‌شده | `0.03` |
| `[guards] min_rate_toman`، `max_rate_toman` | بازه مجاز نرخ (تومان) | `100000`، `2000000` |
| `[hours] saturday` تا `friday` | ساعت کاری هر روز، مثل `09:00-17:00`؛ یا `closed` | شنبه تا چهارشنبه ۹ تا ۱۷، پنجشنبه ۹ تا ۱۳، جمعه بسته |
| `[hours] holidays` | تعطیلات رسمی به تاریخ شمسی، جدا با ویرگول، مثل `1405/09/05, 1405/10/13` | خالی |
| `[web] host` | `0.0.0.0` برای دسترسی از شبکه دفتر، `127.0.0.1` پشت nginx | `0.0.0.0` |
| `[web] port` | درگاه وب‌سایت | `8080` |
| `[web] company_name`، `pricelist_title`، `validity_text` | متن‌های سربرگ لیست | برنا سنسور، لیست قیمت، تا پایان روز کاری |
| `[web] show_rate_on_pricelist` | نرخ دلار مبنا روی لیست چاپی و Excel نوشته شود | `true` |
| `[web] footer_note` | یک خط زیر لیست چاپی، مثلاً وضعیت مالیات بر ارزش افزوده | خالی |
| `[web] session_hours` | چند ساعت بعد کاربر باید دوباره وارد شود | `12` |
| `[web] behind_https_proxy` | فقط وقتی سامانه پشت nginx با HTTPS است `true` شود | `false` |
| `[paths] database`، `products_xlsx`، `log_file`، `secret_key_file` | محل فایل‌های داده | پوشه `data` |

## نقش‌ها

| نقش | چه می‌کند |
|---|---|
| فروش (viewer) | فقط لیست رسمی، نرخ دلار، تاریخچه، چاپ و Excel |
| تأییدکننده (approver) | پذیرفتن یا رد نرخ نگه‌داشته‌شده، ورود نرخ دستی، انتشار و تأیید |
| مدیر سامانه (admin) | همه کارها، به‌اضافه کاربران، کالاها، رویدادها و تنظیمات |

کاربر تازه: منوی **کاربران** در وب‌سایت، یا `python -m borna_pricing create-user ali --role viewer --name "علی رضایی"`.

## نرخ دستی

اگر API در دسترس نیست یا نرخ مشکوک است، تأییدکننده در داشبورد بخش **ورود نرخ دستی** را پر می‌کند: نرخ **به تومان** و منبع (مثلاً «میانگین سه صرافی»). نرخ دستی همان لحظه پذیرفته می‌شود و با نام وارد‌کننده در تاریخچه می‌ماند.

## به‌روزرسانی کالاها و قیمت پایه

1. فایل `data/Borna_Step2-3_Products_Pricing.xlsx` را باز کنید و در برگه **محصولات** تغییر دهید (قیمت پایه، α، کالای تازه، یا حذف ردیف). عنوان ستون‌ها را عوض نکنید.
2. در وب‌سایت: **کالاها** ← فایل را انتخاب کنید ← **پیش‌نمایش تغییرها**.
3. اگر درست بود، **اعمال تغییرها** را بزنید. قیمت‌ها خودکار دوباره حساب می‌شوند و انتشار تازه لازم می‌شود.

کالای حذف‌شده پاک نمی‌شود؛ غیرفعال می‌شود و تاریخچه‌اش می‌ماند.

## پشتیبان‌گیری و بازگردانی

- هر روز اولین بار که سامانه روشن است، یک پشتیبان در `data/backups/` ساخته می‌شود (۳۰ نسخه آخر نگه داشته می‌شود).
- پشتیبان دستی: `python -m borna_pricing backup`
- بازگردانی: سامانه را خاموش کنید، فایل پشتیبان را با نام `borna_pricing.sqlite3` در پوشه `data` جایگزین کنید و دوباره روشن کنید.
- پوشه `data` و فایل `settings.ini` را هر هفته جای دیگری هم کپی کنید.

## دستورهای خط فرمان

در ویندوز به‌جای `python` بنویسید `.venv\Scripts\python`، در اوبونتو `.venv/bin/python`.

| دستور | کار |

| پیام یا مشکل | علت و راه حل |
|---|---|
| `API خطا داد: «توکن یافت نشد.»` | فقط با الان‌چند: توکن در `settings.ini` نیست یا اشتباه است. بدون گیومه بگذارید و سامانه را دوباره روشن کنید. |
| `HTTP 429` | درخواست‌ها از سقف منبع گذشته؛ صبر کنید یا نرخ را دستی وارد کنید. |
| `Python 3.10 or newer was not found` در نصب ویندوز | نصب‌کننده هیچ پایتون ۳.۱۰ یا بالاتری پیدا نکرد. گزارش زیر پیام را ببینید؛ `python.exe` را روی `install_windows.bat` بکشید و رها کنید، یا Python 3.12 را از python.org با تیک «Add python.exe to PATH» نصب کنید. |
| `اتصال به سرور priceto.day برقرار نشد` | اینترنت، DNS یا دیوار آتش. نشانی `https://api.priceto.day/v1/latest/irr/usd` را در مرورگر همان رایانه باز کنید. سامانه ۱۰ دقیقه بعد دوباره تلاش می‌کند. |
| `منبع از ... به‌روز نشده است` | منبع بیش از ۱۸۰ دقیقه از ساعت کاری نرخ تازه نداده است. صبر کنید یا نرخ دستی بدهید. |
| رایانه‌های دیگر سایت را باز نمی‌کنند | `host = 0.0.0.0` باشد و درگاه 8080 در دیوار آتش ویندوز باز باشد. |
| `Address already in use` | برنامه دیگری درگاه 8080 را گرفته؛ در `settings.ini` مقدار `port` را عوض کنید. |
| حروف فارسی در پنجره سیاه به‌هم‌ریخته است | فقط ظاهر پنجره است؛ Windows Terminal بهتر نشان می‌دهد. وب‌سایت درست است. |
| هر خطای دیگر | فایل `data/borna_pricing.log` را برای پشتیبانی بفرستید (توکن در آن نوشته نمی‌شود). |

## امنیت

- priceto.day توکن ندارد. اگر الان‌چند را انتخاب کنید، توکن فقط در `settings.ini` است و در صفحه‌ها و گزارش‌ها با `***` پوشانده می‌شود؛ اگر جایی فاش شد، توکن تازه بگیرید.
- رمزها با PBKDF2 (۶۰۰ هزار دور) ذخیره می‌شوند. پنج بار رمز اشتباه، پنج دقیقه قفل.
- همه فرم‌ها در برابر CSRF محافظت شده‌اند و هر نقش فقط کار خودش را می‌تواند بکند. با تغییر نقش یک کاربر، او باید دوباره وارد شود.
- کلید نشست در `data/secret.key` است؛ آن را به کسی ندهید.

## محدودیت‌های نسخه ۱٫۱

- **منبع رایگان بدون ضمانت:** priceto.day یک پروژه متن‌باز است و در مستنداتش نوشته «فقط برای استفاده شخصی» و ممکن است هر زمان تغییر کند. اگر روزی جواب نداد، نرخ را دستی وارد کنید یا `provider = alanchand` بگذارید.
- **فاصله دریافت:** قدم ۱ «هر ۱۰ دقیقه» تصویب شد، ولی priceto.day هر ۳۰ دقیقه به‌روز می‌شود؛ پس پرسیدن زودتر از ۳۰ دقیقه فایده ندارد. اگر خواستید، `fetch_interval_minutes = 30` بگذارید.
- **مغایرت‌های ۱ تا ۵ فایل قدم ۲** (پارت‌نامبرهای تکراری، کدهای موقت TMP، مالیات بر ارزش افزوده) پیش از استفاده رسمی باید روشن شوند. متن مالیات را در `footer_note` بنویسید.
- **تعطیلات رسمی** را در `holidays` وارد کنید؛ سامانه خودش تقویم تعطیلات ندارد.
- نمایش برای مشتری، کانال بله و دستیار هوش مصنوعی در این نسخه نیست.
